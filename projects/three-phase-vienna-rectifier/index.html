01 · Project overview

Power conversion work grounded in a reference platform.

The project investigated three-phase AC-to-DC conversion and power-factor-correction control using a TI evaluation platform. The target was approximately 700 V DC from a 220 V, three-phase, 60 Hz input.

02 · System architecture

Reference hardware, digital control and laboratory instrumentation.

The setup used the TI TIDM-1000 Vienna Rectifier, a TMDSCNCD28379D controlCARD with a C2000 F28379D controller, modified TI reference firmware, and MATLAB/Simulink prototyping. Testing used an oscilloscope, DMM and electronic load.

The reported control description includes an inner voltage PI controller, an outer power PI controller, current set by a current setpoint, and PWM adjustment based on current comparison and phase correction. This is a functional description of the control work; the page does not present it as a proprietary implementation schematic.

03 · My engineering contributions

Initial implementation, configuration and investigation.

  1. Studied the TI reference implementation and documentation.
  2. Modified reference firmware and implemented initial PWM/controller verification.
  3. Prototyped controller behavior in MATLAB/Simulink.
  4. Configured initial control functions with CCS Theia and PowerSUITE.
  5. Conducted open-loop and preliminary closed-loop testing.
  6. Supported setup, debugging and initial implementation before handoff.

These contributions cover the initial implementation and investigation; the complete system and later validation were team activities.

04 · Development and testing process

Bring-up, observation and handoff.

I worked through dense reference documentation, configured the control loops, investigated excessive input power during early testing, and repeated tests and recalibration while studying voltage and current regulation behavior.

The initial implementation was prepared for continued testing and refinement by the engineering team.

06 · Engineering challenges and lessons

Understanding the control behavior took iteration.

The reported challenges were ambiguous documentation, control-loop complexity, excessive early input power, repeated recalibration, and the need to investigate voltage/current regulation. No quantified root cause or improvement is claimed.
